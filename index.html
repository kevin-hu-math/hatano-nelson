Model, normalization, and browser limits
      
κ is the actual degree. The graph is simple, with Nκ even, and hopping is unnormalized. On a preferred edge u → v, Hvu = eg and Huv = e−g; Hxx = Vx. Preferred directions are independent by default.

      
Root-distance gauge uses H = D(A + diag V)D−1, Dxx = exp(ghx). Its finite spectrum is real and independent of g. Same-shell hopping is 1.

      
For ∥v∥₂ = 1: IPR = ∑x|vx|⁴, ∥v∥₄ = IPR1/4, and ∥v∥∞ = maxx|vx|. The L⁴ norm and IPR therefore encode the same individual-vector statistic. Statistics in a degenerate eigenspace depend on the chosen eigenbasis.

      
Heat maps give arithmetic means in occupied bins. IPR, L⁴ and L∞ always use a fixed linear color scale from 0 to 1, with raw values and no rescaling between runs. Histograms are normalized by the total number of computed eigenvalues and bin area (bin width in the real-line view). Empty bins are blank. Sparse and imported CSV results describe the selected or supplied eigenvalues.

      
The browser runs single-worker Python via Pyodide 0.28.3, NumPy, SciPy, and NetworkX. Full diagonalization costs O(N³) time and O(N²) memory. Sparse LU can also need substantial memory. This runtime uses wasm32, with at most 4 GiB of linear memory and potentially lower limits in a browser. Downloads and plots use additional memory. Use the desktop app for runs beyond the browser's capacity.

      
A small relative eigenpair residual verifies Hv ≈ λv, without bounding nonnormal eigenvalue sensitivity. The app uses double precision. Download your results before closing or reloading the tab. Numerical data stay in your browser; runtime files are downloaded from jsDelivr. Plotly.js is included locally.
